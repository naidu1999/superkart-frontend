# Superkart Frontend — Sales Prediction UI

Streamlit web app for predicting Superkart product sales. Sends product/store details
to the backend API and displays the predicted sales.

🚀 **Live app:** https://naidu1999-superkart-sales-frontend.hf.space

## Backend

Expects the API at `https://naidu1999-superkart-sales-backend.hf.space/predict`
(see [superkart-backend](https://github.com/naidu1999/superkart-backend)).

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
